# Auré — luxury footwear storefront

A fully responsive, client-side storefront for Auré luxury footwear.

## Included
- Responsive luxury editorial design
- Product catalog with category filtering
- Search modal
- Add-to-bag and remove-from-bag interactions
- Persistent shopping bag via localStorage
- Newsletter signup feedback
- Checkout-ready flow (connect Stripe, PayPal, or another provider in `script.js`)

## Run locally
Open `index.html` in a browser, or serve the folder with any static server:

```bash
npx serve .
```

Product data lives in `script.js`; replace the demo image URLs and product information with real inventory before launch.
